# Growth Engine Pitch Canvas

Light, Poppins-based interactive pitch deck.

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173` or `index.html` directly.

- Center hero + 4 cards left / 4 cards right
- Click a card (or the CTA) to expand a modal
- Esc or click the backdrop to close
- Arrow keys move between modules

Static deploy: drop this folder on Vercel or Netlify.
